# Proposal

## Why

当前工具只能对单张图片做霍夫圆检测；视频中的圆形目标需要逐帧观察，手动抽帧再逐张打开效率低，也无法看到参数在连续画面上的效果。需要把现有的检测能力扩展到视频输入，同时保持图片流程和检测算法不变。

## What Changes

- 增加「打开视频」入口，支持至少 MP4、AVI、MOV，并沿用中文路径可用的文件访问约束。
- 打开视频后按当前六个参数逐帧检测，在预览区显示该帧的圆轮廓与圆心。
- 提供播放/暂停与停止控制；播放到末尾自动停止并保留最后一帧结果。
- 参数变化从下一帧起生效，不回算已经显示的帧。
- 视频模式状态栏显示当前帧序号、总帧数、圆数量与单帧检测耗时。
- 视频模式暂不支持音频、跨帧跟踪、跳转定位和导出标注视频；「导出标注图」只在图片模式可用。

## Capabilities

### New Capabilities

- `video-input`: 视频文件导入、元数据读取、逐帧解码与逐帧检测的行为契约，包括中文路径、无法解码文件和资源释放。

### Modified Capabilities

- `detection-workbench`: 工作台增加「打开视频」与播放控制，状态栏在视频模式增加帧信息，并明确视频检测期间界面保持可响应。

## Impact

- 预计涉及 `src/hough_gui/core/` 新增视频读取模块、`src/hough_gui/ui/main_window.py` 的视频线程与控件、`tests/`、`README.md`。
- 复用现有 `detect_circles`、`render_overlay` 与参数模型，不改变图片模式的行为。
- 不新增第三方依赖：视频解码使用现有 OpenCV 自带的 FFmpeg 后端。
- 本次只完成规划与交接记录，不实现视频功能。
