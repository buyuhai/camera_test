# Spec Delta

## Purpose

定义视频文件的导入、元数据读取与逐帧检测行为，使同一套霍夫圆参数可以作用在视频的每一帧上，并在界面上按帧展示检测结果。

## ADDED Requirements

### Requirement: 导入视频文件

系统 SHALL 允许用户从本地选择一个视频文件作为工作媒体，支持至少 MP4、AVI、MOV 容器；文件路径包含非 ASCII 字符（含中文）时同样可用。

#### Scenario: 打开受支持的视频

- **WHEN** 用户通过「打开视频」选择一个可解码的 MP4、AVI 或 MOV 文件
- **THEN** 系统读取视频尺寸、帧率与总帧数，预览区显示首帧的检测叠加结果，状态栏显示当前帧序号与总帧数

#### Scenario: 中文路径

- **WHEN** 所选视频路径包含中文字符
- **THEN** 视频正常打开并播放，不出现编码相关错误

#### Scenario: 无法解码的视频

- **WHEN** 用户选择的文件不是视频或无法解码
- **THEN** 界面显示打开失败提示，当前已加载的图片或视频及其预览保持不变

### Requirement: 逐帧检测

系统 SHALL 对视频的每一显示帧使用当前六个检测参数执行一次检测，并把该帧的圆轮廓与圆心叠加在预览中；不同帧的结果不得串用。

#### Scenario: 每帧结果对应本帧

- **WHEN** 视频连续播放并经过多帧
- **THEN** 每一帧显示的圆数量与位置对应该帧图像，状态栏数量与当前帧叠加结果一致

#### Scenario: 参数变化只影响后续帧

- **WHEN** 视频播放中用户修改任一检测参数
- **THEN** 已经显示的帧不重算，后续帧使用新参数检测

### Requirement: 视频播放控制

系统 SHALL 提供播放/暂停与停止控制，并在视频推进到末尾时停止且保留最后一帧的检测结果。

#### Scenario: 暂停与继续

- **WHEN** 用户在播放中触发暂停，随后再次触发播放
- **THEN** 暂停期间帧序号保持不变，继续后从下一帧接着播放

#### Scenario: 停止

- **WHEN** 用户在播放中触发停止
- **THEN** 视频回到首帧并暂停，预览显示首帧的检测结果

#### Scenario: 播放到末尾

- **WHEN** 视频推进到最后一帧
- **THEN** 播放自动停止，预览保留最后一帧的检测结果，状态栏帧序号等于总帧数

### Requirement: 视频资源释放

系统 SHALL 在视频打开失败、播放结束或窗口关闭时释放解码资源，不得留下仍在运行的视频线程。

#### Scenario: 关闭窗口

- **WHEN** 视频正在播放时用户关闭主窗口
- **THEN** 程序停止视频线程并释放解码资源后退出，不崩溃、不残留进程
