# Spec Delta

## Purpose

定义工具的图片导入与标注图导出行为：单张图片的读取、格式与路径容错，以及把当前检测结果按原始分辨率导出为 PNG 供调试与汇报使用。

## ADDED Requirements

### Requirement: 导入单张图片
系统 SHALL 允许用户从本地选择一个 PNG、JPEG、BMP 或 TIFF 文件作为工作图像，并在预览区显示该图像；文件路径包含非 ASCII 字符（含中文）时同样可用。

#### Scenario: 打开受支持的图片
- **WHEN** 用户通过「打开图片」选择一张 PNG/JPEG/BMP/TIFF 文件
- **THEN** 预览区显示该图像，状态栏显示文件名与像素尺寸（宽 × 高）

#### Scenario: 中文路径
- **WHEN** 所选文件路径包含中文字符
- **THEN** 图像正常加载并显示，不出现编码相关错误

#### Scenario: 不是图片的文件
- **WHEN** 用户选择的文件无法按图片解码
- **THEN** 界面显示读取失败提示，当前已加载的图像与预览保持不变

### Requirement: 打开图片后自动检测
系统 SHALL 在图片加载成功后按当前参数立即执行一次检测，并在预览中显示叠加结果。

#### Scenario: 首次打开
- **WHEN** 尚无图像时用户打开一张图片
- **THEN** 预览显示叠加结果，状态栏显示圆数量与耗时

#### Scenario: 替换当前图像
- **WHEN** 已加载图像时用户打开另一张图片
- **THEN** 预览与状态栏切换为新图像及其检测结果，旧图像不再出现在界面上

### Requirement: 导出标注图
系统 SHALL 将当前预览中的叠加结果以原图像素分辨率导出为 PNG 文件；导出动作仅在已加载图像时可用。

#### Scenario: 正常导出
- **WHEN** 已加载图像且用户触发「导出标注图」并指定保存路径
- **THEN** 该路径生成 PNG 文件，其像素尺寸与原图一致，且包含当前显示的圆的轮廓与圆心

#### Scenario: 无图像时导出不可用
- **WHEN** 尚未加载任何图像
- **THEN** 「导出标注图」动作处于禁用状态，无法打开保存对话框

#### Scenario: 零检出导出
- **WHEN** 已加载图像但当前参数未检出任何圆，用户执行导出
- **THEN** 生成的 PNG 与原始图像内容一致，不含任何圆标记

#### Scenario: 目标路径不可写
- **WHEN** 目标路径无写权限或写入失败
- **THEN** 界面显示错误提示，且既有同名文件保持原内容不变
